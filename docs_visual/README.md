# MT5 ティックリプレイ コントローラー (Tick Replay Controller) 機能紹介資料

本フォルダには、MetaTrader 5 (MT5) 向けティックリプレイシステムの専用リモコンアプリ（Tauri側）の機能およびデザインに関する詳細な資料が格納されています。

---

## 1. アプリケーション概要 (What is it?)

本アプリケーションは、**MetaTrader 5 (MT5) 上で過去の相場（1ミリ秒単位のティックデータ）を動画プレイヤーのように自由自在に再生・巻き戻し・シークし、裁量トレードの検証や練習を圧倒的に効率化するためのデスクトップ型「検証リモコン」**です。

通常、MT5の標準機能だけでは過去のティックデータを細かく巻き戻したり、特定の時間帯へ瞬時にジャンプしたりすることは困難です。本システムを使用することで、まるでYouTubeを見るかのような手軽さで過去相場を動かし、テクニカル指標の挙動確認やエントリー判断の練習を行うことができます。

---

## 2. 主な機能 (Core Features)

### ① インテリジェント・タイムライン (Intelligent Timeline)
検証対象期間の全ティックデータを可視化するスマートなシークバーです。
- **直感的なシーク:** タイムライン上をドラッグまたはクリックするだけで、指定位置へ瞬時に移動（巻き戻し・先送り）します。巻き戻し時には未来のローソク足が自動的に消去され、MT5上のインジケーターも追従して再計算されるため、チャートのズレやちらつきが発生しません。
- **市場セッションの色分け表示:** タイムライン上に東京セッション（緑）、ロンドンセッション（青）、ニューヨークセッション（赤）がそれぞれの時間帯に応じて色分けされ、現在どの市場時間帯を検証しているかが視覚的に分かります。

### ② A-Bループ機能 (A-B Repeat)
特定の価格変動パターン（押し目買い、急落からの反発など）を繰り返し再生して検証するための機能です。
- **SET A / SET B:** ループさせたい開始地点（A）と終了地点（B）を設定すると、その区間内を自動で繰り返し再生します。
- **タイムライン連携:** 設定されたループ範囲は、タイムライン上でも半透明のハイライト領域として視覚的に表示されます。

### ③ 再生・ステップコントロール (Playback Control)
- **PLAY / PAUSE:** リプレイの再生・一時停止を切り替えます。
- **STEP REW / STEP FWD:** 一時停止中に、1ティック（価格更新の最小単位）ずつ進めたり、戻したりできます。細かなプライスアクションの分析に不可欠な機能です。
- **RESET:** 進捗を0%（検証開始時点）に一瞬でリセットします。

### ④ セッション＆時間ジャンプ (Session & Time Jump)
検証効率を極限まで高めるためのスキップ機能です。
- **セッションジャンプ:** 東京(TYO)、ロンドン(LDN)、ニューヨーク(NY)の各主要市場の開始地点へ、ワンクリックで前後ジャンプします。
- **時間ジャンプ:** `1時間前/後`、`10分前/後`、`1分前/後` 単位で時間をスキップできます。

### ⑤ 2種類の再生速度制御 (Dual Speed Modes)
ユーザーの検証目的に合わせて速度調整が可能です。
- **時間比率モード (Time Ratio):** 実際の時間の流れのN倍速で再生します（1.0倍〜10,000.0倍まで無段階）。
- **ティック枚数モード (Tick Count):** 一定の周期ごとに配信されるティックの枚数を固定します（1〜1,000枚）。指標発表時などの激しい値動きをスローモーションで分析する際に最適です。

### ⑥ グローバルショートカット (Global Hotkeys)
リモコンアプリが非アクティブ（MT5チャートを直接クリック・操作している状態）であっても、キーボードのショートカット（Spaceで再生/停止、矢印キーでステップなど）を受け付けてリプレイをコントロールできます。

### ⑦ リモコンモード (Remote Mode) & 最前面表示 (Pin)
- **リモコンモード:** UIが極限までスリムな棒状のバーに変化し、最小限のタイムラインとボタンのみになります。
- **Pin (最前面):** アプリを常に最前面に固定できるため、MT5チャートの邪魔にならない位置に配置して、快適に操作を継続できます。
